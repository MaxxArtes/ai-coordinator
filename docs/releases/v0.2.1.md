# ai-coordinator v0.2.1

Esta versão atualiza os artefatos distribuídos e o pacote npm no GitHub Packages com correções de paridade, classificação de erros e cobertura de testes.

## Novidades e correções

- **Paridade de exclusão de clientes (`exclude_clients`):** a ferramenta `delegate_to_worker` no servidor MCP e no plugin OpenCode V2 agora aceita `exclude_clients`, alinhando o contrato com a API Python (`Coordinator.delegate`) e a CLI (`--exclude-client`).
- **Correção de argumentos no plugin OpenCode V2:** corrigida a posição da flag `--input` na montagem da linha de comando em `delegate_to_worker`.
- **Refinamento da classificação de erros HTTP 403:** `classify()` em `availability.py` deixou de tratar a palavra `"access"` isolada como erro de permissão (que aplicava 1 hora de cooldown), evitando falso-positivo em mensagens de `404` ou `timeout` (ex.: `"model access not found"` ou `"network access timed out"`).
- **Documentação e metadados do GitHub Packages:** o pacote `@maxxartes/ai-coordinator-opencode` e o tarball da release incluem as instruções completas de consumo pelo registro npm do GitHub e metadados `repository`/`publishConfig` versionados diretamente em `plugins/opencode/package.json`.
- **Ampliação da suíte de testes:** adicionados testes cobrindo escopo de bloqueios (`403`, `429` e `quota`), catálogo com TTL, validação de formato/truncamento de saída, agregação de uso/custo e repasse de `exclude_clients`.

## Pacotes da release

- Wheel e distribuição de código-fonte Python (`0.2.1`).
- ZIP da Agent Skill (`v0.2.1`).
- ZIP do plugin Claude Code (`v0.2.1`).
- Tarball npm do plugin OpenCode V2 (`0.2.1`) e publicação em `@maxxartes/ai-coordinator-opencode@0.2.1` no GitHub Packages.
