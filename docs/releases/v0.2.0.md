# ai-coordinator v0.2.0

Esta versão reúne as melhorias desenvolvidas a partir do estudo dos repositórios de Fabio Akita, adaptadas ao ai-coordinator.

## Novidades

- **Avaliação de rotas:** comandos `benchmark` e `benchmark-report`, casos fixos, limite obrigatório `--max-calls`, métricas de tempo/uso e notas de qualidade atribuídas por uma pessoa.
- **Continuidade com ai-memory:** vínculo opcional das tarefas com um workstream por UUID, via `AI_MEMORY_WORKSTREAM_ID` ou argumento explícito. O histórico da conversa permanece no ai-memory.
- **Ambiente dos workers:** lista permitida de variáveis por cliente; o modo de herdar todo o ambiente exige configuração explícita.
- **Compatibilidade verificada:** CI para Python 3.11 e 3.14 em Windows, macOS e Linux, com verificações do pacote Python, construção do servidor MCP, matriz de suporte e pacote OpenCode V2.
- **Distribuição:** versões alinhadas entre Python, marketplace, plugin Claude Code e plugin OpenCode; LICENSE e NOTICE incluídos nos formatos distribuídos.

## Correções

- Isolamento do banco temporário no teste de migração SQLite, incluindo os arquivos WAL e SHM.
- Arquivo de entrada na raiz do plugin OpenCode e metadados `main`/`exports`, incorporando o ajuste de carregamento usado na instalação local.

## Pacotes da release

- Wheel e distribuição de código-fonte Python.
- ZIP da Agent Skill.
- ZIP do plugin Claude Code.
- Tarball npm do plugin OpenCode V2.

## Licença e limites de validação

A v0.2.0 inclui a licença **PolyForm Noncommercial 1.0.0**, com LICENSE e NOTICE nos pacotes. Consulte esses arquivos para os termos aplicáveis.

A matriz de suporte distingue o núcleo Python validado no CI dos plugins empacotados, cuja operação completa depende do cliente nativo. O servidor MCP é opcional e requer `mcp>=2,<3`.
